# Song sources

MIDI files the repertoire was converted from (with `tools/midi2pipit.py` and
`tools/add-accompaniment.py`), kept so the songs can be rebuilt.

- `mutopia/`: Mutopia Project editions placed in the **public domain** by their typesetters
  (BWV Anh. 114, 115, 116, 119, 126; Purcell, Fairest Isle; Bach BWV 1007).
- `personal-bellugi/`: David Bellugi's transcriptions (davidbellugi.com/midi.html), **no licence
  stated**: personal use only, with acknowledgment, like `data/songs/personal/`. Remove both
  before sharing Pipit.
