# Song sources

MIDI files the repertoire was converted from (with `tools/midi2pipit.py` and
`tools/add-accompaniment.py`), kept so the songs can be rebuilt.

- `mutopia/`: Mutopia Project editions, most placed in the **public domain** by their
  typesetters (BWV Anh. 114, 115, 116, 119, 126; Purcell, Fairest Isle; Bach BWV 1007). The
  Handel sonatas (HWV 360/365/369) and Marcello's Ciaccona are **CC BY-SA 3.0**; each song's
  `source` field names its edition.
